# Phase 2: policy and eval

Done 2026-08-31. Nine policy rules, an attempt ledger, three arms over one
action surface, a Python scoring harness, and a three-arm results table on two
layers.

Read `REPORT.md` for the outcome, `RESULTS.md` at the repository root for the
tables and how to read them, and `docs/EVAL-DESIGN.md` for what every metric
means.

| `TESTS.md` | The 37 Go tests and 16 Python tests, named before they existed, plus the red run. |
| `PROBLEMS.md` | What broke while the work happened. |
| `DECISIONS.md` | Choices a later phase would otherwise have to reverse-engineer. |
| `REPORT.md` | The outcome, with the tables and the findings. |
